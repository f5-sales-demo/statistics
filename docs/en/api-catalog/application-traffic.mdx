Traffic rates, errors, latency, throughput, connections, service graphs, and health scores. Required resource or feature: Load balancer, origin, discovered service, or service mesh with telemetry.

## Metric families and dimensions

HTTP rates, errors, latency, throughput, origin traffic, round-trip time (RTT), connections, and Transmission
Control Protocol (TCP) metrics. Group by namespace, site, application type, service, virtual host, virtual
host type, virtual IP address (VIP), node, or cacheability as supported. Health scores cover connectivity,
performance, security, reliability, and overall health. |

Node DDoS selectors expose detected and mitigated packet and bit rates. Use `VHOST` or `NAMESPACE` with `VHOST` grouping where the schema requires it. `NEW_CONNECTION_RATE` does not support a service filter. See the [metric-family guidance](../../service-graph/). |

See [Origin performance](../../origin-performance/) and [Application health](../../application-health/) for measured resource queries.

### Current empty connection series

Graph `ACTIVE_CONNECTIONS` and `NEW_CONNECTION_RATE` were requested with VHOST traffic metrics; no series returned in the measured window. Capture meaningful connection telemetry before presenting a populated example. An empty series does not establish zero traffic. See [Load balancer metrics](../../service-graph/).
