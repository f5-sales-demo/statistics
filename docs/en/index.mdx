This site will explain how to retrieve and understand statistics from the F5 Distributed Cloud API. The content is being prepared as part of the repository's initial onboarding.

## Planned guides

- Find the API operation and resource scope for a statistic.
- Authenticate and make a request, including its time range and other parameters.
- Read the response and handle common request errors.
- Reproduce the request with a complete, reviewed example.

Endpoint-specific instructions and examples will be added as they are verified.
