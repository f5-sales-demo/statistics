Query metrics and logs, load balancer/pool health, and health changes. Required resource or feature: Domain Name System (DNS) zone or DNS load balancer.

## Metric families and dimensions

DNS metrics group by zone, domain, country, query type, response code, client subnet, or answers. Load balancer and pool health queries describe availability; health-change events describe transitions. |
