Traffic, cache metrics, cacheability, access logs, and operation status. Required resource or feature: Content delivery network (CDN) distribution or caching-enabled load balancer.

## Metric families and dimensions

CDN selectors cover traffic and cache behavior by distribution, cache hit type, country, HTTP/TLS version, and point of presence. Access logs provide individual records; cacheability and operation status have separate contracts. |
