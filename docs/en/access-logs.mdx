Complete [shared cURL setup](../setup/) first. Access logs answer which HTTP methods and response classes occurred in a fixed window. Counts describe the returned log population; they are not a sum of request-rate samples. Logging, sampling, and ingestion can differ from API-discovery counters.

## Count the first page

**1. Build a virtual-host query capped at 100 records.**

```bash
XCSH_LOG_QUERY="$(jq -nr --arg vh "$XCSH_VIRTUAL_HOST" \
  '"{vh_name=" + ($vh | tojson) + "}"')"
XCSH_REQUEST="$(jq -nc --arg ns "$XCSH_NAMESPACE" --arg start "$XCSH_START_TIME" \
  --arg end "$XCSH_END_TIME" --arg query "$XCSH_LOG_QUERY" '{
    namespace: $ns, start_time: $start, end_time: $end,
    limit: 100, sort: "DESCENDING", query: $query
  }')"
```

**2. Fetch a page and retain only outcome fields.**

```bash
XCSH_LOG_PAGE="$(curl --silent --show-error --fail-with-body --max-time 60 \
  --request POST \
  --header "Authorization: APIToken ${XCSH_API_TOKEN}" \
  --header 'Content-Type: application/json' \
  --data-binary "$XCSH_REQUEST" \
  "${XCSH_API_URL}/api/data/namespaces/${XCSH_NAMESPACE}/access_logs")"
XCSH_TOTAL_HITS="$(jq -er '.total_hits | tonumber' <<<"$XCSH_LOG_PAGE")"
XCSH_LOG_ROWS="$(jq -ec --arg ns "$XCSH_NAMESPACE" --arg vh "$XCSH_VIRTUAL_HOST" '
  [.logs[]? | (if type == "string" then fromjson else . end)
    | select(.namespace == $ns and .vh_name == $vh)
    | {rsp_code, rsp_code_class, method}]
' <<<"$XCSH_LOG_PAGE")"
XCSH_COUNT_SCOPE=first_page
XCSH_PAGES=1
jq -er --arg scope "$XCSH_COUNT_SCOPE" \
  --arg start "$XCSH_START_TIME" --arg end "$XCSH_END_TIME" \
  --argjson total "$XCSH_TOTAL_HITS" --argjson pages "$XCSH_PAGES" '
  {scope: $scope, start_time: $start, end_time: $end,
   total_hits: $total, pages: $pages, counted: length,
   response_codes: (sort_by(.rsp_code) | group_by(.rsp_code)
     | map({code: .[0].rsp_code, count: length})),
   response_classes: (sort_by(.rsp_code_class) | group_by(.rsp_code_class)
     | map({class: .[0].rsp_code_class, count: length})),
   methods: (sort_by(.method) | group_by(.method)
     | map({method: .[0].method, count: length}))}
' <<<"$XCSH_LOG_ROWS"
```

`total_hits` is the API's matching-log count; `counted` and the grouped counts cover only this page. When `total_hits` exceeds `counted`, these are incomplete counts for the window.

## Count the complete window

Reissue the same fixed-window query with `scroll: true`. Retrieve every page promptly: each cursor is valid for two minutes. The loop caps the export at 100 pages and stops on a scope mismatch or a count mismatch rather than publishing an incomplete total. Increase that bound deliberately for a larger authorized export.

**1. Start a fresh scroll snapshot.**

```bash
XCSH_REQUEST="$(jq -nc --arg ns "$XCSH_NAMESPACE" --arg start "$XCSH_START_TIME" \
  --arg end "$XCSH_END_TIME" --arg query "$XCSH_LOG_QUERY" '{
    namespace: $ns, start_time: $start, end_time: $end,
    limit: 100, sort: "DESCENDING", scroll: true, query: $query
  }')"
XCSH_LOG_PAGE="$(curl --silent --show-error --fail-with-body --max-time 60 \
  --request POST \
  --header "Authorization: APIToken ${XCSH_API_TOKEN}" \
  --header 'Content-Type: application/json' \
  --data-binary "$XCSH_REQUEST" \
  "${XCSH_API_URL}/api/data/namespaces/${XCSH_NAMESPACE}/access_logs")"
XCSH_TOTAL_HITS="$(jq -er '.total_hits | tonumber' <<<"$XCSH_LOG_PAGE")"
XCSH_LOG_ROWS='[]'
XCSH_PAGES=0
```

**2. Collect only response codes, classes, and methods from every page.**

```bash
while :; do
  XCSH_PAGES="$((XCSH_PAGES + 1))"
  test "$XCSH_PAGES" -le 100
  XCSH_PAGE_ROWS="$(jq -ec --arg ns "$XCSH_NAMESPACE" \
    --arg vh "$XCSH_VIRTUAL_HOST" '
    [.logs[]? | (if type == "string" then fromjson else . end)
      | if .namespace == $ns and .vh_name == $vh
        then {rsp_code, rsp_code_class, method}
        else error("Log outside selected scope") end]
  ' <<<"$XCSH_LOG_PAGE")"
  test "$(jq -r 'length' <<<"$XCSH_PAGE_ROWS")" -gt 0 || break
  XCSH_LOG_ROWS="$(jq -nc --argjson rows "$XCSH_LOG_ROWS" \
    --argjson page "$XCSH_PAGE_ROWS" '$rows + $page')"
  XCSH_SCROLL_ID="$(jq -r '.scroll_id // empty' <<<"$XCSH_LOG_PAGE")"
  test -n "$XCSH_SCROLL_ID" || break
  XCSH_REQUEST="$(jq -nc --arg ns "$XCSH_NAMESPACE" --arg cursor "$XCSH_SCROLL_ID" \
    '{namespace: $ns, scroll_id: $cursor}')"
  XCSH_LOG_PAGE="$(curl --silent --show-error --fail-with-body --max-time 60 \
    --request POST \
    --header "Authorization: APIToken ${XCSH_API_TOKEN}" \
    --header 'Content-Type: application/json' \
    --data-binary "$XCSH_REQUEST" \
    "${XCSH_API_URL}/api/data/namespaces/${XCSH_NAMESPACE}/access_logs/scroll")"
done
test "$(jq -r 'length' <<<"$XCSH_LOG_ROWS")" -eq "$XCSH_TOTAL_HITS"
XCSH_COUNT_SCOPE=complete_window
jq -er --arg scope "$XCSH_COUNT_SCOPE" \
  --arg start "$XCSH_START_TIME" --arg end "$XCSH_END_TIME" \
  --argjson total "$XCSH_TOTAL_HITS" --argjson pages "$XCSH_PAGES" '
  {scope: $scope, start_time: $start, end_time: $end,
   total_hits: $total, pages: $pages, counted: length,
   response_codes: (sort_by(.rsp_code) | group_by(.rsp_code)
     | map({code: .[0].rsp_code, count: length})),
   response_classes: (sort_by(.rsp_code_class) | group_by(.rsp_code_class)
     | map({class: .[0].rsp_code_class, count: length})),
   methods: (sort_by(.method) | group_by(.method)
     | map({method: .[0].method, count: length}))}
' <<<"$XCSH_LOG_ROWS"
```

The live API retained a nonempty cursor on an empty final page, so the loop also stops on an empty page. A successful equality check verifies that all matching logs in this snapshot were counted. It does not guarantee all real requests were logged or that late telemetry had arrived. Requery after ingestion delay when verifying a new sequence.

## Focus on failed requests

For a later query, change the matcher to response codes in the 4xx or 5xx classes. To filter a method, add an exact `method="GET"` matcher. Rebuild the request and run the pagination procedure for complete filtered counts.

```bash
XCSH_LOG_QUERY="$(jq -nr --arg vh "$XCSH_VIRTUAL_HOST" \
  '"{vh_name=" + ($vh | tojson) + ",rsp_code=~\"[45].*\",method=\"GET\"}"')"
```

The [bounded verification sequence](../verification/) produces explicit 404 and 503 responses without taking the origin offline. An HTTP status does not identify WAF action: the demo rejection page can return 200, so confirm blocks with [security events](../security-events/).
