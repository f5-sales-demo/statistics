Request and rule-hit counters, events, incidents, suspicious users, and security evidence. Required resource or feature: Web application firewall (WAF) or application security feature.

## Metric families and dimensions

Request, event, and client/server rule-hit counters. Dimensions include virtual host, event type, site, service, instance, rule identifier/severity/tag, firewall mode, and bot classification, depending on the endpoint. |

### Current empty security counters

The application security metrics query with namespace and `VH_NAME` returned HTTP 200 with empty counters.
Retain the measured [WAF counters](../../firewall-metrics/) and authoritative event logs; capture meaningful
points before presenting application security counts. See the [empty security-event metric
response](../../security-events/#empty-security-event-metric-response) for its timestamps and response.

Use [Query concepts](../query-concepts/) for shared request guidance and table conventions.
