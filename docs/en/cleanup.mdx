---
title: Clean up the demo
description: Review a destroy plan while preserving private Terraform state.
sidebar:
  order: 11
---

Keep the demo running after verification. Use this procedure only when the owner decides to retire it.

**1. Load the same ignored `.env` and signed-in Azure subscription used for [deployment](../deployment/).**

**2. Select the existing private state directory.**

```bash
state_dir="${XDG_STATE_HOME:-$HOME/.local/state}/statistics"
test -f "$state_dir/terraform.tfstate"
```

**3. Save a destroy plan.**

```bash
terraform -chdir=terraform plan -destroy -input=false \
  -out="$state_dir/statistics-destroy.tfplan"
```

**4. Review every address and action.**

```bash
terraform -chdir=terraform show -json "$state_dir/statistics-destroy.tfplan" |
  jq -r '.resource_changes[] | [.address, (.change.actions | join(","))] | @tsv'
```

**5. Apply the reviewed destroy plan.**

```bash
terraform -chdir=terraform apply -input=false "$state_dir/statistics-destroy.tfplan"
```

**6. Verify that the demo DNS record and owned namespace objects are absent. Retain the private local state directory and ignored `.env` for later prototype changes unless the operator separately decides to remove them.**
