This release verifies statistics produced by the HTTP demo. The following families need their own deployed responder and a separate live query before they become runnable guides.

| API family | Required demo resource |
| --- | --- |
| Bot defense | Bot defense policy and traffic that exercises its detection paths |
| Client-side defense | Protected browser application with client-side telemetry enabled |
| DDoS | L3/L4 or L7 protection and authorized load or attack simulation |
| DNS | Managed DNS zone, records, and query traffic |
| CDN/cache | CDN load balancer or cache policy with hit and miss traffic |
| Multi-cloud networking | Connected sites, routes, and cross-site flows |
| Kubernetes | Registered cluster or virtual Kubernetes workload |
| Audit logs | Authorized configuration or account activity |

Use the [service graph](../service-graph/), [firewall counters](../firewall-metrics/), [security events](../security-events/), [API discovery](../api-discovery/), and [access logs](../access-logs/) for this HTTP demo.
