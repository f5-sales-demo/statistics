Site/node metrics, topology, flows, cloud-connect bytes, policy hits, and session decisions. Required resource or feature: Connected sites, cloud networks, policy evaluation, or flow collection.

## Metric families and dimensions

Reachability, connection status, latency, throughput, drops, deployments, pods, flows, and node CPU/memory/disk use. Dimensions include site, node, interface, network/connectivity type, source/destination site, segment, and cloud connect. Cloud-connect selectors expose inbound, outbound, and total bytes. |

Hit counters and policy-evaluation latency; session decisions include allowed, denied, and evaluation timeout. Group by the labels documented for the policy, namespace, site, service, or virtual server. |
