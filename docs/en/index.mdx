Use this learning path to deploy a continuously active HTTP demo with bounded traffic and query its
F5 Distributed Cloud statistics with cURL. The demo owns the `statistics` namespace, a blocking application
firewall, API discovery, and an HTTPS load balancer at `statistics.f5-sales-demo.com`. A dedicated
Azure origin serves health and API routes. A dedicated generator sends three marked requests each
minute and one WAF probe every fifth minute.

Start with [prerequisites and shared cURL setup](./setup/). Then follow [deployment](./deployment/) and query the resource you need:

1. [Service graph metrics](./service-graph/)
2. [Application firewall counters](./firewall-metrics/)
3. [Security events](./security-events/)
4. [API discovery statistics and inventory](./api-discovery/)
5. [HTTP access logs](./access-logs/)

Use [verification](./verification/) to compare live samples, [troubleshooting](./troubleshooting/) for common responses, and [cleanup](./cleanup/) when the demo is no longer needed. The [API family catalog](./api-catalog/) lists other telemetry surfaces and their required resources.

The historical prototype informed the request shapes. This guide reports acceptance only from this deployment; historical counts are not reused.
