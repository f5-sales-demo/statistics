Device risk, transaction trends, linked accounts, device history, and data summaries. Required resource or feature: Device Intelligence, Data Intelligence, or Application Traffic Insights.

## Metric families and dimensions

Transaction trends by traffic type, action, application, endpoint, attack intent, geography, user agent, and autonomous system number (ASN). Device queries add risk score, confidence, linked account distribution, signals, and high-risk transactions. Versioned routes can change classification and filter support. |
