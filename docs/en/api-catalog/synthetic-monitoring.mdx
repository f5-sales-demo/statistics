Monitor health, latency, regional history, events, certificates, and security reports. Required resource or feature: Configured synthetic HTTP or DNS monitor.

## Metric families and dimensions

Select the configured HTTP or DNS monitor and supported region and time dimensions. Transport Layer Security (TLS) monitor queries add protocol, grade, and certificate expiration information. Historical measurements and retrieval of existing security reports remain separate from current monitor state.

Use [Query concepts](../query-concepts/) for shared request guidance and table conventions.
