These API families provide statistics for different resources. Each family below needs its own deployed responder and live verification before it can have a runnable guide.

| API family | Required demo resource |
| --- | --- |
| Bot defense | Bot defense policy and traffic that exercises its detection paths |
| Client-side defense | Protected browser application with client-side telemetry enabled |
| Distributed denial of service (DDoS) | Network-layer or application-layer protection and authorized load or attack simulation |
| Transmission Control Protocol (TCP) | TCP load balancer, origin listener, and connection traffic |
| Domain Name System (DNS) | Managed DNS zone, records, and query traffic |
| Content delivery network (CDN)/cache | CDN load balancer or cache policy with hit and miss traffic |
| Multi-cloud networking | Connected sites, routes, and cross-site flows |
| Kubernetes | Registered cluster or virtual Kubernetes workload |
| Audit logs | Authorized configuration or account activity |

For the current HTTP demo, use [HTTP access logs](../access-logs/), [Load balancer metrics](../service-graph/), [Origin performance](../origin-performance/), [Application health](../application-health/), [API activity](../api-discovery/), [WAF metrics](../firewall-metrics/), and [Security events](../security-events/).

## Supported HTTP metrics with no current points

| Surface | Current evidence | Next step |
| --- | --- | --- |
| Graph `ACTIVE_CONNECTIONS` and `NEW_CONNECTION_RATE` | Requested with VHOST traffic metrics; no returned series in the measured window | Capture meaningful connection telemetry before adding a populated example |
| `/api/data/namespaces/{namespace}/app_security/metrics` | Namespace and `VH_NAME` query returned HTTP 200 with empty counters | Retain WAF counters and authoritative event logs; capture meaningful metric points before presenting counts |

These are unavailable telemetry for the measured selector and window. HTTP 200 does not make an empty response a populated result. See [verification](../verification/#empty-security-event-metric-response) for timestamps and the empty security-metric response. DNS, cache/CDN, TCP, sites, and Kubernetes need their own future resources and acceptance.
